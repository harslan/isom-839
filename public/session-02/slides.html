The Formulation Grammar

Three questions, always in order

  • What can I decide? → decision variables. Things under your control, with units.
  • What am I maximizing or minimizing? → one linear expression. Money, hours, carbon.
  • What rules can't I break? → constraints. Capacity, demand, quality, policy, physics.

Master this grammar and you can model almost any resource-allocation problem in business.

The #1 Formulation Trap

Model decisions, not outcomes

Wrong
"Let P = our profit"

Profit is an outcome — it happens to you as a consequence. You can't set it.

Right
"Let D = desks built"

A decision — something a manager can actually order on Monday morning. Profit becomes the objective, computed from decisions.

Litmus test: could you write this variable's value on a work order?

The Answer, In Grammar

Words → algebra

max  70D + 50C
s.t.  4D + 3C ≤ 240  (carpentry)
     2D + 1C ≤ 100  (finishing)
     D, C ≥ 0

Solution: (30 desks, 40 chairs) → $4,100 — and both constraints binding: every hour of both departments used.

Which department deserves one more hour? You can't tell from the solution alone. Hold that for next week.

  • Also: animal feed, fertilizer, steel alloys, coffee, cocktails…

Live · Harbor Fuels

The ratio trick

10,000 gal of Regular (octane ≥ 87) from Stock A (93 octane, $2.80) and Stock B (83 octane, $2.30):

(93A + 83B) / (A + B) ≥ 87  ← not linear ✗

cross-multiply →  93A + 83B ≥ 87(A + B)
→  6A − 4B ≥ 0  ← linear ✓

Solution: 4,000 gal A + 6,000 gal B = $25,000 — octane exactly 87.0. Specs met, never gold-plated.
